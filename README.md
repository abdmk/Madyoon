# مديون — إدارة الديون والمصاريف

تطبيق ويب عربي (RTL) لتتبّع الديون والمصاريف، مع مشاركة الحساب ومساعد ذكي يقترح خطة سداد.

## التقنيات

| الطبقة | الأداة |
|---|---|
| الإطار | Next.js 14 (App Router) + TypeScript |
| قاعدة البيانات والمصادقة | Supabase (PostgreSQL + Auth + RLS + Realtime) |
| الواجهة | Tailwind CSS + مكوّنات بنمط shadcn/ui فوق Radix |
| إدارة الحالة | Zustand |
| الرسوم البيانية | Recharts |
| المساعد الذكي | Anthropic Claude (`claude-opus-5`) |
| الخط | Graphik Arabic (محلي عبر `next/font/local`) |

## التشغيل محلياً

```bash
npm install
cp .env.example .env.local   # ثم املأ القيم
npm run dev
```

### متغيّرات البيئة

| المتغيّر | الوصف |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | رابط مشروع Supabase |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | مفتاح anon العام |
| `ANTHROPIC_API_KEY` | مفتاح Anthropic — للخادم فقط، يشغّل `/chatbot` |

بدون `ANTHROPIC_API_KEY` يعمل التطبيق كاملاً عدا صفحة المساعد الذكي (تُرجع 503 برسالة واضحة).

## إعداد Supabase

1. **تطبيق المخطط** — الملف `supabase/migrations/0001_madyoon_init.sql` يحتوي المخطط الكامل: الجداول، الفهارس، الدوال، المشغّلات (triggers)، سياسات RLS، والاشتراكات اللحظية. طبّقه عبر SQL Editor أو `supabase db push`.
2. **تفعيل Google OAuth** — من Authentication → Providers → Google، وأضف `Client ID` و`Client Secret`.
3. **روابط إعادة التوجيه** — أضف في Authentication → URL Configuration:
   - `http://localhost:3000/auth/callback` (للتطوير)
   - `https://<نطاقك>/auth/callback` (للإنتاج)

> **أول مستخدم يسجّل الدخول يصبح مديراً تلقائياً** (المشغّل `bootstrap_first_admin`). بعدها تُدار الصلاحيات من `/admin/users`.

## الأمان

- **RLS مفعّل على كل جدول.** المستخدم يرى بياناته فقط، أو بيانات من شاركه حسابه صراحةً.
- **صلاحيات المشاركة على مستويين**: `read` (اطّلاع) و`write` (تعديل)، مفروضة في السياسات لا في الواجهة.
- **رفع الصلاحية محمي** بمشغّل `guard_role` — لا يستطيع المستخدم ترقية نفسه إلى مدير حتى لو استدعى الـ API مباشرة.
- **دوال الإدارة** (`admin_stats`, `admin_users`, `admin_analytics`) تتحقّق من الصلاحية داخلياً، ومحجوبة عن دور `anon`.
- **قبول الدعوات** يمرّ عبر `accept_invite` كدالة `SECURITY DEFINER`، لأن صف الدعوة غير مرئي لمن سيستخدمه قبل أن يصبح ملكاً له.
- **بيانات المساعد الذكي** تُجلب من الخادم بهوية المستخدم — لا تُرسل أرقام من المتصفّح.

تم التحقّق من العزل باختبار ذاتي (`supabase/migrations/…_rls_isolation_selftest`) يغطّي: الملكية، المشاركة، نطاق الكتابة، ومنع رفع الصلاحية.

## ملاحظات تقنية

- **تصدير PDF** يتم عبر طباعة المتصفّح (`window.print()`) مع ورقة أنماط مخصّصة، لأن مكتبات PDF المبنية على canvas تكسر تشكيل الحروف العربية.
- **تصدير CSV** يضيف BOM ليقرأ Excel الترميز UTF-8 بشكل صحيح.
- **العمل دون اتصال**: خدمة عامل (`public/sw.js`) تخزّن هيكل التطبيق والأصول الثابتة فقط. الطلبات إلى Supabase و`/api` لا تُخزَّن أبداً — الرصيد القديم أسوأ من عدم وجود رصيد.
- **الأرقام** تُعرض باللاتينية داخل النص العربي (`font-variant-numeric: tabular-nums`) لسهولة المسح البصري في الجداول.
